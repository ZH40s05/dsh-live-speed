# 实时速度看板

本版为 `dsh-live-speed@0.2.5`，在官方 DSH 0.2.2-rc.3 上适配。来源为用户提供的 `dsh-live-speed-0.1.0.zip`，SHA-256 为 `2c242153d62c9e629060a1468b177cedde4bc0c9d066044f803a9ea4b61ffe45`。

输入框下方「活动」显示首 token 等待和实时正文速度。浏览器滚动统计最近 2.5 秒收到的正文 Unicode 字符，保留 Markdown 标记，不计推理块和工具参数。模型完成后显示「上一步」平均 tok/s，计算使用服务商上报的总输出 token 和 DSH 原生生成时长。这个口径可能包含推理和工具调用。点击读数可查看会话平均模型吞吐、首 token、模型和工具耗时。设置里的「简洁」模式保留速度读数。底栏的字色、字体尺寸、行高和数字样式跟随 DSH 原生用量栏。原版「用量」负责 token 及缓存统计。

插件只读取浏览器侧原生 Chat、Trajectory 和会话统计，使用公开的 `conversation.composer.dock` 活动条目。按模型步骤与重试重置采样，使用浏览器单调时钟计量采样间隔。宿主入口仅用于加载插件。无第三方依赖。

弹层保留旧插件的圆角数据行、强调色和脉冲指示，背景、模糊与阴影使用 DSH 主题。蓝点按旧版每秒明暗变化一次，即使系统关闭动画也仍作为输出状态提示。详细模式的模型和工具耗时保留旧版的芯片和扳手图标。原版会话和每轮用量弹层打开时在视窗内定位，滚动聊天时仍可阅读。原版统计和关闭交互由 DSH 处理。

在 DSH 插件页启用或停用。生产安装和版本回退使用 Work 原有 A/B 流程。
